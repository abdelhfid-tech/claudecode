Tester le jeu

Trois façons d’essayer la version {{numero}}. La plus simple est la première : elle marche sur tous les téléphones.

{{P.RESERVE}}

1 Dans le navigateur, tout de suite

Le jeu s’ouvre dans la page : rien à installer, aucun compte.

Jouer maintenant

Le garder sur l’écran d’accueil

  • iPhone (Safari) : le bouton Partager, puis « Sur l’écran d’accueil ».
  • Android (Chrome) : le menu ⋮, puis « Installer l’application » ou « Ajouter à l’écran d’accueil ».

Une fois ouvert, le jeu se rouvre même sans réseau.

2 Android : l’application de test

{{#apk}}

Télécharger l’APK de test

{{apk.nom}} · {{apk.taille}} · version {{apk.numero}}

Empreinte SHA-256, pour vérifier le fichier : {{apk.sha256}}

L’installer, en trois gestes

  1. Sur le téléphone, touchez « Télécharger l’APK de test ».
  2. Ouvrez le fichier téléchargé. Android demande d’autoriser l’installation depuis le navigateur : autorisez-la.
  3. Touchez « Installer », puis ouvrez ISNAD.

C’est une version de test, hors du Play Store : Android peut prévenir qu’elle vient d’une source inconnue. Une fois le jeu installé, vous pouvez retirer cette autorisation dans les réglages.

Bientôt

En attendant, le jeu se joue dans le navigateur (1), et se garde sur l’écran d’accueil.

3 iPhone : TestFlight

{{#testflight}}
  1. Installez TestFlight, l’application d’Apple pour les versions de test (sur l’App Store).
  2. Sur l’iPhone, ouvrez l’invitation : rejoindre le test d’ISNAD.
  3. Dans TestFlight, touchez « Installer ».
{{/testflight}} {{^testflight}}

Bientôt

{{/testflight}}

En attendant — ou sans TestFlight — le jeu se joue dans Safari (1), et se garde sur l’écran d’accueil.

Votre partie

La partie reste sur l’appareil, dans le navigateur ou dans l’application : rien n’est envoyé nulle part.

Pour la mettre à l’abri, ou la passer sur un autre appareil : dans la halte (le bouton ☰), « Exporter la partie », puis « Enregistrer le fichier ». Pour la reprendre : à l’écran-titre, « Importer une partie ».

Sur iPhone, le jeu gardé sur l’écran d’accueil a sa propre partie, distincte de celle de Safari : passez-la de l’un à l’autre par le fichier.

Une erreur ?

Une date, une attribution, une formulation, un écran qui se coince : écrivez-nous, avec le numéro de la version ({{numero}}) et, si possible, une capture d’écran.
