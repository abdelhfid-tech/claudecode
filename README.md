# Guide du Questionnaire Familial - Projet Commercial

## 📋 Contenu du projet

Ce dossier contient tout ce dont vous avez besoin pour créer et gérer votre questionnaire Google Form destiné à vos parents concernant votre projet de boutique au Maroc.

## 📁 Fichiers

1. **questionnaire-parents-projet-commercial.md** - Le questionnaire complet avec toutes les questions en français et arabe
2. **guide-installation-extensions.md** - Instructions pour installer les extensions PDF
3. **template-analyse-gemini.md** - Template pour analyser les réponses avec Gemini

## 🚀 Démarrage rapide

### Étape 1 : Créer le Google Form
1. Allez sur [forms.google.com](https://forms.google.com)
2. Créez un nouveau formulaire
3. Copiez-collez les sections du fichier `questionnaire-parents-projet-commercial.md`

### Étape 2 : Installer l'extension PDF
1. Suivez les instructions dans `guide-installation-extensions.md`
2. Configurez l'export automatique des réponses en PDF

### Étape 3 : Partager le formulaire
1. Cliquez sur "Envoyer" dans Google Forms
2. Copiez le lien
3. Partagez-le via WhatsApp à vos parents

### Étape 4 : Analyser les réponses
1. Une fois les réponses reçues, exportez le PDF
2. Utilisez le template dans `template-analyse-gemini.md` pour analyser avec Gemini

## 💡 Conseils importants

- **Soyez patient** : Donnez à vos parents au moins une semaine pour répondre
- **Testez d'abord** : Remplissez le formulaire vous-même pour vérifier que tout fonctionne
- **Restez ouvert** : Les réponses peuvent vous surprendre, acceptez-les avec bienveillance
- **Suivez** : Prévoyez une réunion famille après les réponses pour discuter

## 🎯 Objectifs du questionnaire

1. Clarifier le patrimoine de votre père au Maroc
2. Obtenir l'accord et les conditions pour le projet commercial
3. Définir la structure de l'association
4. Comprendre les craintes et espoirs de vos parents
5. Donner une voix à votre mère

## ❤️ Approche recommandée

Ce questionnaire est conçu avec respect et empathie. Il ne s'agit pas d'un interrogatoire mais d'un dialogue familial constructif. Présentez-le à vos parents avec amour et patience.
